# Tabular Data Preprocessor B

High-performance tabular data preprocessing and feature scaling utilities for machine learning pipelines.

## Overview

This skill handles automated scaling, outlier detection, and normalization for numerical feature sets in Python.

### Workflow

1. Load your dataset into pandas DataFrame format.
2. Call standard scaling functions across all continuous features.
3. Validate that transformed column variance equals one.
